# Phoumy Sisavath — Portfolio

Minimal personal portfolio for a Backend Developer / DevOps Engineer.

## Develop

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

This repo is a user site (`username.github.io`). Push the built site to the `gh-pages` branch (or enable Pages from GitHub Actions):

```bash
npm run deploy
```

Then in the GitHub repo settings → Pages, set the source to the `gh-pages` branch.

Content lives in `src/data/content.ts` and `about-me.txt`.
